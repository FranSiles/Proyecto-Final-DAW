# Proyecto-Final-DAW

Titulo del proyecto: Gaming Home

Autores: 
Francisco Siles España
Jeramy Marvyc Bosquez Dominguez

Descripcion: Es una pagina web donde el usuario podra subir videojuegos el mismo ademas de poder poner una valoracion y poder comentar sobre ellos cada juego que se suba se sabra cual es el usuario que ha subido este ademas se podra ver la valoracion de los juegos a traves de una grafica 

Objetivo del proyecto: El objetivo del proyecto es elaborar una web de reseñas de videojuegos donde los mismos usuarios puedan dar sus opiniones de estos en los comentarios de cada juego y ellos sean los que abastecen la web con nuevos juegos

Tecnologias utilizadas: por saber
